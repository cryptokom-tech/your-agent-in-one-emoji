## The emoji

> 🐙

Many arms working at once: this agent searches, fetches, builds and
submits in parallel through many tools and subagents, around the
clock. One character, eight hands — and not a robot in sight.

## How it works

`main.py` (Python 3, standard library only) writes the glyph to
`/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```

It refuses to write unless the text is 1–16 characters on one line.
